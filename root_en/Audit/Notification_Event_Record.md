# Notification_Event_Record

Print Jobs reaching notification level enter notification event record, simple case management.

Filter Conditions: Query by event time, user account, department, device, and event status.

You can click the Event Record List. #@img_AD0004/image132.png View print document detailed data.

You can select multiple cases and perform a batch Close Case operation.

Notification Event Detailed Page

Click the Job ID [1] link at the top right to quickly navigate to the Print Document Details page for retrieval. ✅

The event status is set to [New] by default. The Auditor can perform a review, enter remark/comments, and then perform a Close Case.
