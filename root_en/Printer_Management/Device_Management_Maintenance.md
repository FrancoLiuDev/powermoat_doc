**Physical Printer Registration: Device Management Maintenance\> \[HP OXPD\]：Binding registration for HP printers**

  #@img_PRT0001/image95.png

1\. Select the registered printer server: Authentication, authorization, and job records for this MFP will be hosted on this server.

2\. Select the module to process

3\. Check the device to bind

4\. Click [Register] button to perform binding

**Multiple devices can be registered together. Reference message for registration results:**

  #@img_PRT0001/image96.png

**Unbind**

  #@img_PRT0001/image98.png

1. Select the module to unbind

2. Check the device to bind

3. Click [Unregister] button to perform unbinding

**[Usage]：**

- Device Type：HPOXPD\_MFP /HPOXPD\_SINGLE Allows device usage page retrieval。
