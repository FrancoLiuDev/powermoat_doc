> **Printer management data will be automatically imported from printers in Windows Control Panel (no need to add)**

> **Printer Settings:**
>
  #@img_PRT0002/image101.png

> Device: If there is a corresponding physical device, please set it. Not set indicates a virtual printer.
>
> Driver Type: Please set the driver type for this printer，PCL/PostScript/NA

  #@img_PRT0002/image102.png


**Enable Control: After enabling, the system will monitor print jobs for this printer and perform related operations.**

**Control Queue Printing: After enabling, the system will control print jobs until they are authorized for release.**

**Enable Audit: After enabling, print jobs passing through this printer must be audited before release.**

**Enable Backup: After enabling, print jobs passing through this printer will be backed up (Control must be enabled).**

**Enable Watermark: After enabling, print jobs passing through this printer will have watermarks applied.**

**QoS Type: L/M/H, default performance is L, adjustable according to situation.**

**Watermark Printer: If this printer queue cannot perform watermark operations normally, a proxy printer queue can be set to execute watermarks.**
