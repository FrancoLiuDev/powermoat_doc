# Standard_Reports

PowerMoat provides multiple standard reports covering users, printers, security, etc. Export formats support CSV, EXCEL, and PDF.

## List of Standard Reports with Brief Descriptions

| Category     | Report Name             | Usage Description                           |
|----------|----------------------|------------------------------------|
| User   | User Print Statistics       | View usage status of each user           |
|          | Department Print Statistics         | Analyze print usage status of each department           |
|          | User Group Print Statistics   | Statistic user group usage status           |
|          | Uncollected Print Statistics       | Show usage status of uncollected prints         |
|          | Cost Center Print Statistics     | Statistic print usage status by cost center       |
| Printer   | Printer List           | List all printer setting information in the system     |
|          | Device List             | List all device and setting information in the system     |
|          | Printer Print Statistics       | Statistic printer usage               |
|          | Device Print Statistics         | Statistic device usage                 |
|          | Device Print ESG Statistics      | Statistic device ESG usage              |
|          | HP Device Usage Statistics       | Statistic device usage by HP usage page       |
|          | HP Device Consumable Alert Report   | Statistic device consumable usage by HP consumable page  |
| Security     | Risk Index Report         | Analyze document risk index                 |
|          | No OCR Result Report        | 列出未成功perform OCR 的文件紀錄      |
