# Application_System_Role_Description

**Application system roles are divided into:**

| **Administrator**     | **Approves all system setting permissions, except audit management.**             |
|----------------|--------------------------------------------------------|
| **Auditor**     | **Approves audit management relevant permissions (ex: audit retrieval, keyword settings, etc.)** |
| **User**     | **General user, can query personal print records.**                 |
| **Audit Manager** | **Approves audit management relevant permissions (ex: audit retrieval, keyword settings, etc.)** <br> **Manage Auditors(ex: Specify audit scope, dual authentication rules, etc.)** |
| **Support**       | **Can use transactional functions (ex: Report Management)**                   |
