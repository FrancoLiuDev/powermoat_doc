# HP Print Driver Installation

## 1. Driver Installation Environment Preparation

### 1.1 Hardware Requirements

N/A

### 1.2 Operational Requirements

- First obtain the HP driver installation file (ex. upd-pcl6-x64-7.0.1.24923)

### 1.3 Installation Steps

- Click the installer (Open)
  
  #@img_A0004/0013.png

- Click Extract (Unzip), default extraction path: C:\HP Universal Print Driver

  #@img_A0004/0014.png

  #@img_A0004/0015.png

- Close the installer and proceed without printer installation
  
- Open Print Server -> Driver section, perform Add Driver operation

  #@img_A0004/0003.png

  #@img_A0004/0004.png

- Select system type
  
  #@img_A0004/0005.png

- Select Have Disk -> Open HP driver folder C:\HP Universal Print Driver

  #@img_A0004/0006.png

  #@img_A0004/0007.png

  #@img_A0004/0016.png

- Continue with the installation
  
  #@img_A0004/0017.png

- Select v7.0.1

  #@img_A0004/0018.png

- Verify if the item "FF Multi-model Print Driver 2" has been added to confirm successful installation
  
  #@img_A0004/0019.png
