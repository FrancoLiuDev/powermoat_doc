# HP Print Driver Installation

## 1. Driver Installation Environment Preparation

### 1.1 Hardware Requirements

N/A

### 1.2 Operational Requirements

- Must first obtain the HP driver installation file (ex. upd-pcl6-x64-7.0.1.24923)

### 1.3 Installation Steps

- Click installer(Open)
  
  #@img_A0004/0013.png

- Click unzip(Unzip)，Unzip path defaults to C:\HP Universal Print Driver

  #@img_A0004/0014.png

  #@img_A0004/0015.png

- 關閉安裝程式,perform無Printer安裝
  
- Open Print Server -> Driver item, operate Add Driver

  #@img_A0004/0003.png

  #@img_A0004/0004.png

- Select system type
  
  #@img_A0004/0005.png

- 選擇 Have Disk -> Open HP driver folder C:\HP Universal Print Driver

  #@img_A0004/0006.png

  #@img_A0004/0007.png

  #@img_A0004/0016.png

- Sequentialperform安裝
  
  #@img_A0004/0017.png

- Select v7.0.1
  #@img_A0004/0018.png

- Check if there is a new item FF Multi-model Print Driver 2  Check if installation is successful
  
  #@img_A0004/0019.png
