# 通報事件紀錄

達到通報等級的列印Job 進入通報事件紀錄，簡易的案件管理。

  #@img_AD0004/image130.png

篩選條件: 可依照事件時間、使用者帳號、部門、裝置及事件狀態來查詢。

事件紀錄清單可點選 #@img_AD0004/image130.png 查看事件詳細資料。

事件紀錄清單可點選 #@img_AD0004/image132.png 查看列印文件的詳細資料。

可以多筆選取後進行批次結案作業。

  #@img_AD0004/image133.png
 
通報事件詳細頁面

右上方 Job ID \[1\] 連結，可以快速連結到列印文件詳細頁進行調閱。

事件狀態預設為 \[新建立\]，稽核員可進行審核並輸入備註意見後進行結案。
