# 2026/01/02 使用者無法列印

## 問題概述

台塑特定使用者無法列印文件,PSS 列印分錄顯示ERROR

## 一、綁定前環境準備

### 1.1 進入SSMS 連入DB

- 開SSMS 連入DB
- 輸人使用者及密碼

## 二、定位問題

### 1.1 Print Job 狀態

- 檢視PSSDB -> dbo.print_job 檢視
- 加入條件 where account = '使用者帳號' 找到用戶的列印紀錄
- 欄位error_msg 驗證PrintJob 發生錯誤!!
- 欄位 submit_print_id 是印表機ID

### 1.2 查訊是哪個 Print

- 檢視PSSDB -> dbo.print 檢視
- 查到該ID 的印表機
-

### 1.3 查訊系統LOG

- PSSLOG-> monitor -> Printer 目錄
- 找到1.2查詢到的列表機
- 找到事發時間段,查看該時間印表的問題LOG
- 此次問題是 Call API 發生錯誤
- 需要到 PSSLOG-> webmonitor 文件查看問題
- 到事出的時間段查看,本次問題是 auth_user not found (使用
  者不存在)
  
### 1.4 檢視使用者

- 使用者帳號維護沒有該使用者
- 員工資料維護(進入用者帳號前),有發現該員工編號
- 跳過排程滙入, 進行手動滙入使用者帳號 ,發生錯誤

### 1.5 檢視使用者

- 檢視PSSDB -> dbo.auth_user 檢視
  - select account, count(*) from auth_user_temp group by account having count(*) > 1;
  - 發現 auth_user_temp 有多筆重複以至滙入時發生問題
