# HP 列印驅動程式安裝

## 一、驅動程式安裝環境準備

### 1.1 硬體需求

N/A

### 1.2 作業需求

- 需先取得 HP 驅動程式安裝檔 (ex. upd-pcl6-x64-7.0.1.24923)

### 1.3 安裝步驟

- 點擊安裝程式(Open)
  
  #@img_A0004/0013.png

- 點擊解壓縮(Unzip)，解壓路徑預設 C:\HP Universal Print Driver

  #@img_A0004/0014.png

  #@img_A0004/0015.png

- 關閉安裝程式,進行無印表機安裝
  
- 打開 Print Server -> Driver項目,操作 Add Driver

  #@img_A0004/0003.png

  #@img_A0004/0004.png

- 選擇系統類型
  
  #@img_A0004/0005.png

- 選擇 Have Disk -> 開啟 HP 驅動程式資料夾 C:\HP Universal Print Driver

  #@img_A0004/0006.png

  #@img_A0004/0007.png

  #@img_A0004/0016.png

- 依續進行安裝
  
  #@img_A0004/0017.png

- 選取 v7.0.1
  #@img_A0004/0018.png

- 確認是否有新增項目 FF Multi-model Print Driver 2  確認安裝是否成功
  
  #@img_A0004/0019.png
