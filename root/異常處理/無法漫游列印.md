# 列印失敗

## 列印文件未出現在儀表板
　　
　　確認使用者送出列印後,工作是否出現在列印文件儀表板
　　
```plantuml
@startuml
start
if (儀表板是否有列印工作?) then (Yes)
  :-->列印登錄及派送流程;
else (No)
    if (PSS consumer & monitor 是否啟動?) then (Yes)
        :-->是否開啟管制佇列列印;
    else (No)
        :啟動PSS服務再次列印;
    endif
endif

stop
@enduml
```

## 是否開啟管制佇列列印
　　
　　檢查[印表機管理維護]漫游列印印表機設定

```plantuml
@startuml
start

if (是否開啟管制佇列列印?) then (Yes)
  :-->漫游列印佇列錯誤流程;
else (No)
  :開啟管制佇列列印;
endif

stop
@enduml
```

## 漫游列印佇列錯誤流程
　　
　　檢查為何漫游列印工作法顯示在漫游佇列中

```plantuml
@startuml
start
:檢查漫游列印佇列;

if (使用者權限不足?) then (Yes)
  :-->檢查使用者權限;
elseif (使用者權限不足-彩色?) then (Yes)
  :-->檢查使用者權限;
else (No)
  :其它錯誤需調閱LOG;
endif

stop
@enduml
```

## 列印登錄及派送流程
　　
    檢查為何漫游列印工作無法派送至印表機

```plantuml
@startuml
start
:使用者登錄及列印;

if (可登錄?) then (Yes)
  :-->檢查使用者列印操作;
else (No)
  :-->事務機登錄失敗;
endif

stop
@enduml
```

## 檢查使用者列印操作

 檢查送出列印進行列印工作反應

```plantuml
@startuml
start
:點選我的文件並列印;

if (可進行列印並出紙?) then (Yes)
  :操作成功完成;
else (No)
  :-->檢查事務機連線;
endif

stop
@enduml
```

## 事務機登錄失敗

 檢查使用者事務機登錄功能

```plantuml
@startuml
start
:事務機是否有綁定;
/' 檢查使用者帳號 '/
if (己綁定?) then (Yes)
    if (帳號存在?) then (Yes)
        :其它錯誤需調閱LOG;
    else (No)
        :新建帳號或檢查帳號匯入;
    endif 
else (No)
  :綁定事務機再次操作;
endif

stop
@enduml
```

## 　檢查事務機連線

 檢查事務機設備是否在線

```plantuml
@startuml
start


if (可以事務機後台?) then (Yes)
    if (系統印表機狀態Ready?) then (Yes)
        :如無法列印需調閱LOG或重新啟動 Windows Splooer服務;
    else (No)
        :重新開機事務機;
    endif 
else (No)
  :檢查事務機網路連線;
endif

stop
@enduml
```
