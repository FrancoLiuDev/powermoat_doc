# 應用系統角色說明

**應用系統角色區分為以下:**

| **管理員**     | **具備所有系統設定的權限，除了稽核管理。**             |
|----------------|--------------------------------------------------------|
| **稽核員**     | **具備稽核管理之相關權限(ex: 稽核調閱、關鍵字設定等)** |
| **使用者**     | **一般使用者，可查詢個人的列印紀錄。**                 |
| **稽核管理員** | **具備稽核管理之相關權限(ex: 稽核調閱、關鍵字設定等)** <br> **管理稽核員(ex: 指定稽核範圍、雙認證規則等)** |
| **支援**       | **可以使用事務性功能(ex: 報表管理)**                   |
