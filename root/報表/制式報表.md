# 制式報表

PowerMoat 提供了多份制式化報表，涵蓋了使用者、印表機、安全等面向的各式報表，匯出格式支援 CSV、EXCEL、PDF 三種格式。

## 制式報表清單及簡易說明

| 類別     | 報表名稱             | 用途說明                           |
|----------|----------------------|------------------------------------|
| 使用者   | 使用者列印統計       | 查看每位使用者的使用狀況           |
|          | 部門列印統計         | 分析各部門的列印使用狀況           |
|          | 使用者群組列印統計   | 統計使用者群組的使用狀況           |
|          | 未取件列印統計       | 顯示列印後未取件的使用狀況         |
|          | 成本中心列印統計     | 依成本中心統計列印的使用狀況       |
| 印表機   | 印表機清單           | 列出系統內所有印表機設定的資訊     |
|          | 裝置清單             | 列出系統內所有裝置及設定的資訊     |
|          | 印表機列印統計       | 統計印表機的使用情況               |
|          | 裝置列印統計         | 統計裝置的使用情況                 |
|          | 裝置列印ESG統計      | 統計裝置的ESG使用情況              |
|          | HP裝置用量統計       | 以HP用量頁統計裝置的使用情況       |
|          | HP裝置耗材預警報表   | 以HP耗材頁統計裝置的 耗材使用情況  |
| 安全     | 風險指數報表         | 分析文件的風險指數                 |
|          | 無OCR結果報表        | 列出未成功進行 OCR 的文件紀錄      |
